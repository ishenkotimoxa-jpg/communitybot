# Вопросы пользователей

1. Добавьте бота в группу с командой ОСО и разрешите ему отправлять сообщения.
2. Отправьте в группе `/chat_id` (если ботов несколько — `/chat_id@имя_бота`).
3. Добавьте полученный ID в `.env`: `SUPPORT_CHAT_ID=-1001234567890` (замените пример своим ID).
4. Перезапустите бота через `start_bot.cmd`.

Пользователь открывает «Часто задаваемые вопросы» → категорию → вопрос → ответ.
В `FAQ_CATEGORIES` в `faq.py` находятся 14 готовых вопросов и ответов для МИФИ:
объединения, студенческий совет (ОСО), единое окно помощи и общежития.
Кнопка «Задать вопрос» доступна на каждом уровне и позволяет отправить один
текстовый вопрос до 3000 символов. Есть возврат к вопросам темы, категориям и главному меню.
«Единое окно помощи» — онлайн-приёмная проректора по молодёжной политике на сайте МИФИ.
Описание раздела основано на предоставленном тексте соцсетей ОСО. Обращение к проректору
отправляется через сайт; кнопка «Задать вопрос» в боте по-прежнему ведёт к команде ОСО.
Ссылки на официальные страницы МИФИ хранятся рядом с содержимым категорий.

В группе нажмите «Ответить» **на сообщение бота с вопросом**. Ваш ответ будет
отправлен пользователю в личный чат с ботом, ответом на его исходное сообщение.
Можно отвечать текстом, фотографией, голосовым сообщением или документом.
Сообщения альбома отправляются отдельно. Несколько ответов на один вопрос допустимы.
Обычные сообщения группы и ответы на посторонние сообщения не пересылаются.
Отвечать может любой участник настроенной группы, в том числе анонимный администратор.
Правка уже отправленного ответа не пересылается: отправьте новый ответ на вопрос.

Бот подтверждает доставку в группе либо сообщает об ошибке. Если пользователь
удалил исходный вопрос, ответ придёт отдельным сообщением. Если заблокировал
бота — доставка невозможна.

Связи между вопросами и пользователями сохраняются в `support.sqlite3` рядом
с `bot.py`; сохраните этот файл при переносе бота. Содержимое вопросов в базу
не записывается. После перезапуска можно отвечать на ранее полученные вопросы;
пользователю, который ещё не отправил вопрос, нужно снова нажать «Задать вопрос».
Без `SUPPORT_CHAT_ID` FAQ доступен, а приём новых вопросов отключён.

Для ответов на сообщения бота отключать Privacy Mode не требуется:
[Telegram Bots FAQ](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get).
